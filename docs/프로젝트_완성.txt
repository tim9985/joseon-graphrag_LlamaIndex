 새 PC에서 실행하기
====================================================================================================

1. joseon_graphrag 폴더를 USB/클라우드로 복사

2. 새 PC에서 필수 프로그램 설치:
   - Python 3.11+
   - Ollama (llama3.1:13b 모델 다운로드)
   - Neo4j Desktop (APOC 플러그인 설치 필수!)

3. joseon_graphrag 폴더에서 PowerShell 실행:

   cd joseon_graphrag
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

4. 실행:

   python graph_builder.py input/4.세종.txt
   또는
   python batch_process.py

자세한 내용은 START.md 파일 참고!
