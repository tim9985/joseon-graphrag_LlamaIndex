## 🔧 문제 해결

### Neo4j 연결 실패

**증상:**
```
❌ Neo4j 연결 실패: Failed to resolve address
```

**해결:**
1. Neo4j 실행 확인:
   ```bash
   # Windows
   neo4j.bat console
   
   # Mac/Linux
   neo4j start
   ```

2. `.env` 파일 확인:
   ```env
   NEO4J_URI=bolt://sungjun:7687  ← 주소 확인
   NEO4J_DATABASE=youngmin7       ← DB 이름 확인
   ```

3. 인스턴스 주소 확인:
   - `sungjun`이 올바른 호스트명인지 확인
   - IP 주소로 시도: `bolt://192.168.x.x:7687`
   - localhost로 시도: `bolt://localhost:7687`

### Ollama 연결 실패

**증상:**
```
❌ Ollama 연결 실패: Connection refused
```

**해결:**
1. Ollama 서비스 시작:
   ```bash
   ollama serve
   ```

2. 모델 다운로드:
   ```bash
   ollama pull exaone3.5:7.8b
   ```

3. 모델 확인:
   ```bash
   ollama list
   ```

### 임베딩 생성 느림

**증상:**
```
노드 임베딩: 5%|█ | 50/1000 [02:30<47:30, 3.00s/it]
```

**해결:**
1. GPU 사용 확인:
   ```python
   import torch
   print(torch.cuda.is_available())  # True여야 함
   ```

2. CPU 모드는 정상 (GPU보다 느림)

3. 첫 실행은 모델 다운로드로 느림 (정상)

### 검색 결과 없음

**증상:**
```
⚠️ 검색 결과가 없습니다
```

**해결:**
1. 임베딩 확인:
   ```bash
   python test_youngmin7.py
   ```

2. 임베딩 재실행:
   ```bash
   python embed_youngmin7.py
   ```

3. Neo4j에서 직접 확인:
   ```cypher
   MATCH (n) WHERE n.embedding IS NOT NULL RETURN count(n)
   ```
