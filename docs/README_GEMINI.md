# 조선왕조 GraphRAG QA 시스템 (Gemini API 버전)

Google Gemini API를 사용한 조선왕조 지식 그래프 질의응답 시스템입니다.

## 🌟 주요 기능

### 4가지 검색 모드

1. **벡터 검색 (Vector Search)**
   - 의미 기반 유사도 검색
   - 임베딩 벡터 매칭
   - 동의어/유사 표현 이해

2. **키워드 검색 (Keyword Search)**
   - 문자열 직접 매칭
   - 빠른 검색 속도
   - 정확한 개체명 검색

3. **Cypher 검색 (Text-to-Cypher)**
   - **Gemini API로 자연어를 Cypher로 자동 변환**
   - 복잡한 그래프 패턴 질의
   - 정확한 구조적 검색

4. **하이브리드 검색 (Hybrid Search)**
   - 벡터 + 키워드 + 그래프 탐색 통합
   - 최고의 정확도

## 📦 설치

### 1. 필수 패키지 설치

```bash
pip install google-generativeai neo4j python-dotenv sentence-transformers numpy
```

### 2. 환경 변수 설정

`.env` 파일을 생성하고 다음 내용을 추가:

```bash
# Gemini API (필수)
GEMINI_API_KEY=your_gemini_api_key_here

# Neo4j (필수)
NEO4J_URI=bolt://127.0.0.1:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_password
NEO4J_DATABASE=youngmin7
```

### 3. Gemini API 키 발급

1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속
2. "Create API Key" 클릭
3. 생성된 키를 `.env`에 추가

## 🚀 사용 방법

### 대화형 모드 (기본)

```bash
python qa_gemini.py
```

대화형 모드에서 사용할 수 있는 명령어:
- `/mode vector` - 벡터 검색 모드로 변경
- `/mode keyword` - 키워드 검색 모드로 변경
- `/mode cypher` - Cypher 검색 모드로 변경
- `/mode hybrid` - 하이브리드 모드로 변경
- `/help` - 도움말
- `/exit` - 종료

### 단일 질문 모드

```bash
# 하이브리드 모드로 질문
python qa_gemini.py -q "세종의 아버지는?"

# Cypher 모드로 질문 (Gemini가 자동으로 Cypher 생성)
python qa_gemini.py -q "태종이 편찬한 책은?" -m cypher

# 벡터 모드로 질문
python qa_gemini.py -q "훈민정음" -m vector

# 키워드 모드로 질문
python qa_gemini.py -q "성종" -m keyword
```

### 배치 모드

```bash
# questions.txt 파일의 질문들을 순차적으로 처리
python qa_gemini.py --batch questions.txt -m hybrid
```

`questions.txt` 예시:
```
세종의 아버지는?
태종이 편찬한 책은?
임진왜란이 일어난 시기는?
정조의 정치적 업적은?
```

### 벡터 모델 없이 실행 (더 빠른 시작)

```bash
# 키워드/Cypher 모드만 사용 (임베딩 모델 로드 생략)
python qa_gemini.py --no-vector -m cypher
```

## 💡 검색 모드 비교

| 모드 | 속도 | 정확도 | 장점 | 단점 |
|------|------|--------|------|------|
| **Vector** | 중간 | 높음 | 의미 이해, 유연성 | 임베딩 필요 |
| **Keyword** | 빠름 | 중간 | 빠른 속도, 간단 | 형태소 정확히 일치 필요 |
| **Cypher** | 느림 | 매우 높음 | 복잡한 패턴, 정확한 구조 검색 | Gemini API 호출 필요 |
| **Hybrid** | 느림 | 최고 | 모든 장점 통합 | 가장 느림 |

## 📊 Gemini API의 장점

1. **무료 티어 제공**
   - 분당 15회 요청 (RPM: 15)
   - 일일 1,500회 요청
   - 개인 프로젝트에 충분

2. **높은 성능**
   - Gemini 2.0 Flash: 빠르고 효율적
   - Gemini 1.5 Flash: 안정적
   - 한국어 지원 우수

3. **Text-to-Cypher**
   - 자연어를 Cypher 쿼리로 자동 변환
   - 복잡한 그래프 질의 가능
   - Ollama 대비 더 정확한 쿼리 생성

## ⚠️ 주의사항

### Rate Limiting

Gemini API 무료 티어는 **분당 15회 요청 제한**이 있습니다.
- 코드에서 자동으로 4초 간격으로 요청 제어
- 429 에러 발생 시 자동 재시도 (최대 3회)

### API 키 보안

- `.env` 파일을 `.gitignore`에 추가하세요
- API 키를 코드에 직접 하드코딩하지 마세요
- 공개 저장소에 업로드하지 마세요

## 🔧 트러블슈팅

### 1. GEMINI_API_KEY 오류

```
ValueError: GEMINI_API_KEY 환경변수가 설정되지 않았습니다.
```

**해결:** `.env` 파일에 `GEMINI_API_KEY=your_key` 추가

### 2. Neo4j 연결 실패

```
[오류] Neo4j 연결 실패: Couldn't connect to 127.0.0.1:7687
```

**해결:** 
- Neo4j Desktop에서 데이터베이스 시작
- `.env`의 `NEO4J_URI`, `NEO4J_PASSWORD` 확인

### 3. Rate Limit 초과

```
[경고] Rate Limit 도달. 60초 대기 중...
```

**해결:** 자동으로 재시도되므로 대기 (무료 티어: 분당 15회)

### 4. 안전 필터링

```
[경고] 안전 필터링: ...
```

**해결:** 질문을 더 중립적으로 수정

## 🆚 Ollama 버전과의 차이

| 항목 | Gemini 버전 (qa_gemini.py) | Ollama 버전 (qa_multimodal.py) |
|------|----------------------------|--------------------------------|
| **LLM** | Google Gemini API | 로컬 Ollama |
| **설치** | API 키만 필요 | Ollama + 모델 다운로드 필요 |
| **속도** | 인터넷 속도 의존 | 로컬 GPU/CPU 의존 |
| **비용** | 무료 (제한 있음) | 완전 무료 |
| **정확도** | 높음 (특히 Text-to-Cypher) | 중간 |
| **오프라인** | 불가능 | 가능 |
| **추천** | 인터넷 연결 O, 정확도 중시 | 로컬 환경, 프라이버시 중시 |
