# 조선왕조 GraphRAG 다중 검색 QA 시스템 사용 설명서

## 📚 개요

`qa_multimodal.py`는 조선왕조 지식 그래프에 대해 4가지 검색 모드를 CLI로 선택할 수 있는 고급 질의응답 시스템입니다.

### 🎯 4가지 검색 모드

| 모드 | 방식 | 장점 | 적합한 질문 |
|------|------|------|------------|
| **vector** | 임베딩 유사도 | 의미 기반 검색, 동의어 이해 | "세종의 업적", "훈민정음 만든 사람" |
| **keyword** | 문자열 매칭 | 빠름, 정확한 개체명 매칭 | "태종", "임진왜란" |
| **cypher** | Text-to-Cypher | 복잡한 쿼리, 정확한 관계 탐색 | "세종의 아버지의 업적" |
| **hybrid** | 벡터+키워드+그래프 | 가장 높은 정확도, 모든 질문 대응 | 모든 유형 (권장) |

## 🚀 빠른 시작

### 1. 대화형 모드 (기본)

```bash
python qa_multimodal.py
```

대화형 모드에서 사용 가능한 명령어:
- `/mode <모드>` - 검색 모드 변경 (vector/keyword/cypher/hybrid)
- `/help` - 도움말 표시
- `/exit` 또는 `/quit` - 종료

**예시:**
```
💬 질문 (hybrid): 세종의 아버지는?
💬 질문 (hybrid): /mode cypher
✓ 검색 모드 변경: CYPHER
💬 질문 (cypher): 태종의 업적은?
💬 질문 (cypher): /exit
```

### 2. 단일 질문 모드

```bash
# 하이브리드 모드 (기본)
python qa_multimodal.py -q "세종의 아버지는?"

# 키워드 검색 모드
python qa_multimodal.py -q "세종의 아버지는?" -m keyword

# Cypher 쿼리 모드
python qa_multimodal.py -q "성종과 정치적 경쟁자는?" -m cypher

# 벡터 검색 모드
python qa_multimodal.py -q "훈민정음을 만든 사람" -m vector
```

### 3. 배치 모드 (여러 질문 자동 처리)

```bash
# questions.txt 파일 생성
echo "세종의 아버지는?" > questions.txt
echo "임진왜란은 누구 재위 중?" >> questions.txt
echo "태종의 업적은?" >> questions.txt

# 배치 실행
python qa_multimodal.py --batch questions.txt -m hybrid
```

### 4. 벡터 모델 없이 실행 (빠른 시작)

임베딩 모델 로딩 시간을 줄이려면:

```bash
# 키워드/Cypher 모드만 사용
python qa_multimodal.py --no-vector -m keyword

# 대화형 모드 (키워드/Cypher만)
python qa_multimodal.py --no-vector
```

## 📖 상세 사용법

### CLI 옵션

```bash
python qa_multimodal.py [OPTIONS]
```

**옵션:**

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `-m, --mode` | 검색 모드 선택 | `hybrid` |
| `-q, --question` | 단일 질문 | - |
| `--batch FILE` | 배치 모드: 질문 파일 경로 | - |
| `--no-vector` | 벡터 모델 로드 안 함 (빠른 시작) | False |
| `-v, --verbose` | 상세 초기화 로그 출력 | False |
| `-h, --help` | 도움말 표시 | - |

## 🔍 검색 모드 상세 설명

### 1️⃣ Vector 모드 (벡터 임베딩 검색)

**작동 원리:**
1. 질문을 임베딩 벡터로 변환
2. 노드/관계의 임베딩과 코사인 유사도 계산
3. 상위 k개 결과 반환
4. LLM으로 답변 생성

**장점:**
- 의미 기반 검색 (동의어, 유사 표현 이해)
- "아버지는?" → [아버지] 관계 자동 매칭

**단점:**
- 임베딩 모델 로딩 시간 필요
- 일부 정확성 트레이드오프

**예시:**
```bash
python qa_multimodal.py -m vector -q "효종의 아버지는?"
```

**출력:**
```
================================================================================
💬 질문: 효종의 아버지는?
🔍 검색 모드: VECTOR
================================================================================

📊 벡터 임베딩 검색 중...

--------------------------------------------------------------------------------
📋 검색 결과:
--------------------------------------------------------------------------------

✅ 노드 5개:
  1. 효종 (King) - 점수: 0.987
  2. 인조 (King) - 점수: 0.856
  3. 봉림대군 (Person) - 점수: 0.743
  ...

✅ 관계 3개:
  1. 효종 --[아버지]--> 인조 - 점수: 0.921
  ...

🤖 LLM 답변 생성 중...

================================================================================
💡 답변:
================================================================================
효종의 아버지는 인조입니다. 지식 그래프에서 효종과 인조를 연결하는 '아버지' 
관계가 확인되었습니다.
================================================================================
```

---

### 2️⃣ Keyword 모드 (키워드 매칭 검색)

**작동 원리:**
1. 질문에서 키워드 추출 및 변형 생성
   - 원본: "세종 업적"
   - 변형: "세종_업적", "세종업적", "세종", "업적"
2. 각 키워드로 노드명/관계 타입 CONTAINS 검색
3. 중복 제거 및 상위 k개 반환

**장점:**
- 빠른 속도
- 정확한 개체명 매칭
- 벡터 모델 불필요

**단점:**
- 문자열이 정확히 포함되어야 함
- 의미 유사성 이해 안 됨

**예시:**
```bash
python qa_multimodal.py --no-vector -m keyword -q "태종"
```

**키워드 변형 예시:**
```
입력: "세종의 아버지"
변형:
  1. "세종의 아버지" (원본)
  2. "세종의_아버지" (공백→언더스코어)
  3. "세종의아버지" (공백 제거)
  4. "세종", "아버지" (단어 분리)
  5. "세종 아버지" (조사 제거)
  6. "세종_아버지"
```

---

### 3️⃣ Cypher 모드 (Text-to-Cypher)

**작동 원리:**
1. LLM이 자연어 질문을 Cypher 쿼리로 변환
2. Neo4j에서 Cypher 실행
3. 결과를 LLM이 자연어로 요약

**장점:**
- 복잡한 패턴 검색 가능
- 정확한 그래프 관계 탐색
- 프로그래밍 불필요

**단점:**
- LLM이 잘못된 Cypher 생성 가능
- 개체명 철자가 정확해야 함

**예시:**
```bash
python qa_multimodal.py --no-vector -m cypher -q "성종과 정치적 경쟁자는?"
```

**출력:**
```
================================================================================
💬 질문: 성종과 정치적 경쟁자는?
🔍 검색 모드: CYPHER
================================================================================

⚙️ Cypher 쿼리 생성 및 실행 중...

생성된 Cypher 쿼리:
  MATCH (성종)-[r:정치적_경쟁자]-(competitor) 
  RETURN competitor.name, labels(competitor) 
  LIMIT 10

결과: 3개

================================================================================
💡 답변:
================================================================================
성종의 정치적 경쟁자는 한명회, 신숙주, 정인지입니다. 이들은 성종과 정치적_경쟁자 
관계로 연결되어 있습니다.
================================================================================
```

---

### 4️⃣ Hybrid 모드 (하이브리드 검색) ⭐ 권장

**작동 원리:**
1. **벡터 검색** (가능한 경우): 노드 5개 + 관계 5개
2. **키워드 검색**: 노드 5개 + 관계 5개
3. **중복 제거** 및 점수 기반 정렬
4. **그래프 탐색**: 최상위 노드 주변 1~2홉 탐색
5. **LLM 답변 생성**

**장점:**
- 가장 높은 정확도
- 모든 유형의 질문 대응
- 벡터와 키워드의 장점 결합

**단점:**
- 가장 느림 (여러 검색 실행)
- 벡터 모델 필요

**예시:**
```bash
python qa_multimodal.py -m hybrid -q "세종의 아버지는?"
```

**출력:**
```
================================================================================
💬 질문: 세종의 아버지는?
🔍 검색 모드: HYBRID
================================================================================

🔄 하이브리드 검색 중 (벡터 + 키워드 + 그래프)...

--------------------------------------------------------------------------------
📋 검색 결과:
--------------------------------------------------------------------------------

✅ 노드 7개:
  1. 세종 (King) - 점수: 0.987
  2. 태종 (King) - 점수: 0.921
  3. 충녕대군 (Person) - 점수: 0.856
  ...

✅ 관계 5개:
  1. 세종 --[아버지]--> 태종 - 점수: 0.954
  2. 태종 --[아들]--> 세종 - 점수: 0.932
  ...

✅ '세종' 주변 개체 15개

🤖 LLM 답변 생성 중...

================================================================================
💡 답변:
================================================================================
세종의 아버지는 태종입니다. 지식 그래프에서 세종과 태종을 연결하는 '아버지' 관계가 
확인되었으며, 역방향으로 태종과 세종을 연결하는 '아들' 관계도 존재합니다.
================================================================================
```

## 💡 사용 팁

### 1. 모드 선택 가이드

```
질문 유형별 권장 모드:

✅ "세종의 아버지는?" → cypher 또는 hybrid
   (명확한 관계 쿼리)

✅ "훈민정음을 만든 사람" → vector
   (의미 기반 검색)

✅ "태종" (개체 정보) → keyword
   (단순 개체명 검색)

✅ "조선 초기 주요 인물" → hybrid
   (복잡한 질문)

✅ 확실하지 않을 때 → hybrid (기본값)
```

### 2. 성능 최적화

```bash
# 빠른 시작 (벡터 모델 스킵)
python qa_multimodal.py --no-vector -m keyword

# 간단한 질문 → keyword
python qa_multimodal.py --no-vector -m keyword -q "태종"

# 복잡한 질문 → hybrid
python qa_multimodal.py -m hybrid -q "세종의 아버지의 업적"
```

### 3. 대화형 모드 활용

```bash
# hybrid로 시작
python qa_multimodal.py

# 대화 중 모드 전환
💬 질문 (hybrid): 세종의 아버지는?
💬 질문 (hybrid): /mode cypher
✓ 검색 모드 변경: CYPHER
💬 질문 (cypher): 태종의 업적은?
💬 질문 (cypher): /mode keyword
✓ 검색 모드 변경: KEYWORD
💬 질문 (keyword): 훈민정음
```

### 4. 배치 처리

여러 질문을 한 번에 처리:

```bash
# test_questions.txt 생성
cat > test_questions.txt << EOF
세종의 아버지는?
임진왜란은 누구 재위 중?
태종의 업적은?
성종과 정치적 경쟁자는?
훈민정음을 만든 사람은?
EOF

# 실행
python qa_multimodal.py --batch test_questions.txt -m hybrid
```

## 🔧 문제 해결

### 1. 임베딩 모델 로딩 느림

**문제:** `SentenceTransformer` 로딩에 시간이 오래 걸림

**해결:**
```bash
# 벡터 모드 불필요 시 스킵
python qa_multimodal.py --no-vector -m keyword
```

### 2. "검색 결과가 없습니다"

**원인:**
- 키워드가 그래프에 없음
- 철자 오류

**해결:**
```bash
# 1. 다른 모드 시도
python qa_multimodal.py -m vector -q "세종"  # 의미 기반 검색

# 2. 키워드 확인
python qa_multimodal.py -m keyword -q "世宗"  # ❌ 한자
python qa_multimodal.py -m keyword -q "세종"  # ✅ 한글
```

### 3. Cypher 쿼리 실패

**원인:** LLM이 잘못된 Cypher 생성

**해결:**
```bash
# 1. 질문을 더 명확하게
python qa_multimodal.py -m cypher -q "성종의 정치적 경쟁자를 찾아줘"  # ❌ 모호함
python qa_multimodal.py -m cypher -q "성종과 정치적_경쟁자 관계는?"  # ✅ 명확함

# 2. hybrid 모드 사용 (Cypher 실패 시 다른 검색 사용)
python qa_multimodal.py -m hybrid -q "성종의 정치적 경쟁자"
```

### 4. 답변이 부정확함

**원인:** 검색 결과가 관련 없음

**해결:**
```bash
# verbose 모드로 검색 과정 확인
python qa_multimodal.py -v -q "세종의 아버지는?" -m hybrid

# 결과 확인 후 모드 변경
```

## 🎯 실전 예시

### 예시 1: 관계 질문

```bash
python qa_multimodal.py -q "세종의 아버지는?" -m hybrid
```

**기대 답변:**
> 세종의 아버지는 태종입니다.

### 예시 2: 업적 질문

```bash
python qa_multimodal.py -q "태종의 업적은?" -m cypher
```

**생성된 Cypher:**
```cypher
MATCH (태종)-[r]-(achievement)
WHERE type(r) IN ['편찬함', '저술함', '주도함', '실시함']
RETURN achievement.name, type(r)
LIMIT 10
```

**기대 답변:**
> 태종은 조선경국전을 편찬하고, 호패법을 실시했으며, 육조직계제를 확립했습니다.

### 예시 3: 의미 검색

```bash
python qa_multimodal.py -q "훈민정음 만든 사람" -m vector
```

**기대 답변:**
> 훈민정음을 창제한 사람은 세종대왕입니다.
