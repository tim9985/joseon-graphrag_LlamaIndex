## 🔧 문제 해결

### 백엔드가 시작되지 않음
```powershell
# Flask 설치 확인
pip install flask flask-cors

# 수동으로 백엔드 시작
python qa_api.py
```

### 프론트엔드가 열리지 않음
```powershell
# 의존성 재설치
npm install

# 수동으로 프론트엔드 시작
npm start
```

### Neo4j 연결 오류
- Neo4j Desktop에서 `youngmin7` 데이터베이스가 실행 중인지 확인
- `.env` 파일의 Neo4j 설정 확인

### Ollama 연결 오류
```powershell
# Ollama 서버 시작
ollama serve

# 모델 다운로드
ollama pull exaone3.5:7.8b
```
